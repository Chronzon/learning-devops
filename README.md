# Learning DevOps

My public learning repository for building practical DevOps skills through notes, small projects, and reproducible workflows.

I have prior Kubernetes experience and am using this repository to refresh the fundamentals before expanding into CI/CD, infrastructure as code, observability, and cloud delivery.

## Goals

- Keep concise, useful notes in English.
- Build small projects that demonstrate a complete delivery workflow.
- Prefer reproducible commands, versioned configuration, and clear trade-offs.
- Record what worked, what failed, and what I would improve.
